대시보드 열기 →

이 안내 파일과 실행 HTML을 같은 폴더에 두세요.

먼저 하는 일

  1. 대시보드 열기를 누르거나 실행 HTML 파일을 Chrome/Edge에서 엽니다.
  2. 왼쪽 학습 가이드에서 배송 문의 시나리오의 새 자료를 만듭니다.
  3. 규칙 기반 초안 생성 → 모의 답변 기록 → 해결 처리를 체험합니다.
  4. 다음에는 취소 요청 시나리오에서 상담원 → 관리자 역할을 전환해 승인과 실행이 다른 단계임을 확인합니다.
  5. 마치기 전에 설정 · 백업 → 전체 JSON 백업을 받습니다.
실제 고객 발송, 주문 취소, 환불, AI 호출은 하지 않습니다. 화면 안에서 실제로 바뀌는 것은 가상/업로드한 로컬 자료입니다.

AI와 함께 고칠 때

소스의 AGENTS.md와 CLAUDE.md에 작업 규칙이 있습니다.

docs/AI_NEXT_TASK.md를 첫 요청으로 사용하세요. 우선 소스를 읽고 전체 설치·검사를 확인한 뒤 한 기능씩 진행합니다.

preview.html을 직접 수정하지 말고 src를 고쳐 다시 빌드하세요.

소스 실행 명령

개발용 Node.js 22.12 이상 환경에서, 프로젝트 폴더를 열고 실행합니다. 단순 체험은 이 설치가 필요 없습니다.

npm install
npm run dev

검사·실행본 재생성:

npm run typecheck
npm test
npm run build
npm run build:vite

첫 설치의 package-lock.json은 네트워크가 되는 환경에서 생성해 커밋하세요. 이 패키지에는 미검증 잠금 파일을 임의로 넣지 않았습니다.

검증한 것과 남은 것

업무·자료 테스트 60개, 브라우저 시나리오 7개, 도메인 타입 검사와 단일 HTML 빌드를 통과했습니다.

제작 환경의 네트워크 제약으로 전체 npm 설치·React 타입 검사·Vite 빌드는 완료하지 못했습니다. GitHub CI·실제 배포도 아직 실행하지 않았습니다. 다음 AI 작업에서 먼저 확인하도록 문서화했습니다.

브라우저 실습은 메모리 페이지의 임시 저장 모드에서 검사했습니다. 실제 파일/배포 주소의 지속 저장은 사용하는 브라우저에서 확인하고 백업을 유지하세요.
