# 다음 AI 개발 도구에 붙여 넣을 요청

나는 백엔드 개념을 배우는 입문자입니다. 이 프로젝트를 바탕으로 쇼핑몰 고객지원 업무를 이해하고 기능을 한 개씩 발전시키고 싶습니다.

먼저 AGENTS.md, CLAUDE.md, README.md, docs/FEATURE_MATRIX.md, docs/ARCHITECTURE.md, docs/DATA_MODEL.md, docs/TEST_REPORT.md를 읽고 실제 소스와 비교해 주세요.

이번 작업 범위는 다음까지입니다.
1. 이 앱이 어떤 업무를 처리하고 어떤 기능은 로컬/모의인지 한국어로 설명해 주세요.
2. 의존성을 설치하고 전체 타입 검사, 도메인 검사, 단위 테스트, 두 빌드를 실행하세요. package-lock.json을 정상 생성해 검토하세요. 네트워크나 실행 환경 때문에 못한 검사는 따로 적어 주세요.
3. 기존 기능을 없애거나 전체를 다시 만들지 마세요. 실패가 있으면 원인과 최소 수정 범위를 제시하고 회귀 테스트를 추가하세요.
4. 실행된 화면에서 CSV 가져오기 → 문의 연결 → 취소 요청 → 관리자 승인 → 실행 재검사 → 모의 답변 → 해결 → 백업 흐름을 확인하세요.
5. 변경한 파일, 통과/실패한 명령, 내가 눌러볼 순서를 알려주세요. 이 단계에서 실제 고객 발송·환불·AI 호출을 연결하지 마세요.

그 다음에만 하나의 개선을 골라 진행합니다. 우선 후보는 ‘브라우저 자료 저장과 백업 안정성’입니다. IndexedDB로 옮기는 것이 필요한지 현재 한도와 실제 사용량을 보고 먼저 설명해 주세요. 필요가 없으면 유지하세요.

실제 로그인·온라인 저장이 다음 목표로 확정되면 docs/BACKEND_ROADMAP.md에 따라 데이터 접근 정책, 서버 재검사, 마이그레이션과 실패 복구를 먼저 설계하세요. 키를 코드에 넣지 말고 개인 자료를 공개 저장소에 올리지 마세요.

기능을 하나 추가할 때마다 ‘이 사업에서 왜 필요한가 → 어떤 자료가 들어오는가 → 무엇이 바뀌는가 → 내가 어떻게 확인하는가’를 설명해 주세요. 마지막에는 이해 확인 질문 하나를 해 주세요.
