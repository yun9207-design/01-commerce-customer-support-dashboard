# 구현 범위표 · v1.0.0

| 항목 | 현재 상태 | 제외·주의 |
|---|---|---|
| 주문/문의 CSV | 로컬 실제 기능 | UTF-8만, XLSX/PDF/이미지 직접 해석 미지원 |
| 검사 미리보기·오류 보고서 | 로컬 실제 기능 | 오류 일부를 무시하고 부분 반영하지 않음 |
| 주문 조회 | 업로드/가상 자료 기준 | 실시간 쇼핑몰 조회 아님 |
| 문의 등록·검색·필터·담당 | 로컬 실제 기능 | 외부 채팅 연결·팀 동시 작업 아님 |
| 초안 | 주문·정책 양식 처리 | LLM/생성형 AI 미연결 |
| 답변 복사 | 브라우저 권한 사용 | 불가능하면 TXT 파일로 대체 |
| 고객 발송 | 로컬 모의 답변 기록 | 이메일·문자·채팅 서버로 전송하지 않음 |
| 취소 정책 | 학습 조건과 버전 | 법률 판단·실제 운영 정책 아님 |
| 승인/반려 | 로컬 실제 상태 전이 | 관리자 선택기는 인증 아님 |
| 주문 취소 | 로컬 주문의 모의 변경 | 실쇼핑몰 취소·결제 환불 없음 |
| 배송 상태 변경 | 외부 갱신을 가정하는 실습 | 택배사 동기화 없음 |
| 상태 재검사 | 로컬 규칙 검사 | 서버 트랜잭션·다중 사용자 잠금 아님 |
| 이력·리포트 | 현재 자료에서 계산 | 법적 증빙·위변조 방지 로그 아님 |
| 저장 | localStorage 또는 현재 탭 메모리 | 브라우저 용량·환경에 따라 실패 가능 |
| 백업 복원 | 구조 검사·미리보기·명시적 교체 | 암호화·외부 클라우드 저장 아님 |
| 학습 진도 | 사용자의 수동 이해 체크 | 지식 평가·실습 자동 통과 판정 아님 |
| GitHub 작업 | 소스·설명·CI/배포 예시 제공 | 사용자 저장소 생성/연결/업로드 미실행 |
| 정식 서비스 운영 | 미구현 | 로그인·사용자 격리·서버·실연동·모니터링 필요 |

처음부터 모든 고객센터 기능을 넣지는 않았다. 환불, 교환, 여러 상품 부분 취소, 상품 추천, 음성 상담, 자동 학습, 첨부 이미지, 실시간 알림, 결제 구독은 이 버전의 범위 밖이다. UI에 ‘곧 연결’ 버튼을 놓고 작동하는 기능처럼 표현하지 않았다.
